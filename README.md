# 원준희 프론트엔드 포트폴리오

HTML · CSS · JavaScript 정적 사이트입니다. 패키지 설치 및 별도 빌드 과정은 없습니다.

## 로컬 검토

`source` 폴더에서 Python이 설치된 경우:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

http://127.0.0.1:4173/ 에서 확인합니다. 현재 Codex 작업에서는 번들 Python으로 이 서버를 실행했습니다. 공개 배포 및 Git push는 수행하지 않았습니다.

## 콘텐츠 관리

- `js/portfolio-data.js`: 기존 43개 작업과 가상화폐 프로젝트. 공동구매는 하나의 데이터로 개발/디자인 카테고리에 노출합니다.
- `js/common.js`: 카테고리, 페이지 이동, 설명과 이미지가 있는 상세 모달, 키보드/포커스 처리.
- `css/common.css`: 기존 그래픽 스타일과 반응형 레이아웃. 본문은 눈누에서 확인한 Pretendard, 영문 그래픽은 Poetsen One입니다.
- 공동구매 이미지는 사용자에게 같은 프로젝트임을 확인한 SELLERCONNECT 기존 UI 디자인 자료입니다.
- 기술·역할은 사용자 제공 사실과 기존 포트폴리오 데이터를 근거로 작성했습니다. 기존 디자인/퍼블리싱의 세부 기술과 과정은 확인되지 않은 사실을 추가하지 않았습니다.

## 확인 결과

- 네 JavaScript 파일의 `node --check` 통과.
- 46개 프로젝트의 ID 중복 없음, 이미지·썸네일 파일 누락 없음.
- 실제 브라우저 1440px 데스크톱 / 390px 모바일에서 주요 화면과 상세 모달 확인.
- 여섯 카테고리, 페이지 전환, 공동 상세, 텍스트 전용 프로젝트, Escape 닫기, Tab 순환, 포커스 복귀, 방향키 카테고리 이동, 내부 앵커 및 이메일 공개 확인.
- 기존 서비스 링크 주소와 새 창 속성 유지. 외부 사이트의 현재 운영 상태는 보증하지 않습니다.
- 외부 YouTube 배경 음악은 임베드 제한 오류(150)가 관찰되었습니다. 오류 시 비활성 상태와 안내를 표시합니다. 기존 음원은 보존했습니다.

## 추가 프로젝트

- 클린온: 사용자 제공 allclean 소스와 직접 담당 범위 확인을 근거로 UI·반응형·프론트엔드 작업 추가. 이미지는 실제 로컬 실행 화면입니다.
- 먹깨비 신문고: 사용자 제공 Vue 3 소스와 담당 범위 확인을 근거로 추가. 더미 데이터 UI와 운영·서버 검증을 구분합니다.
- 두 프로젝트의 AI 활용 여부는 확인되지 않아 임의로 기재하지 않았습니다.
- 탭은 영문 / Poetsen One을 유지하고, 스프링 hover 이동 대상에서 제외하여 배경색만 변경합니다.

- 상세페이지 및 소셜미디어 작업 기술은 사용자가 확인한 Photoshop·Illustrator·Figma로 반영했습니다. 상세페이지의 구현 과정/문제 해결 항목은 표시하지 않습니다.
- 먹깨비는 기존 의존성을 설치한 후 번들 Node로 원본 Vue CLI 빌드를 실행해 성공했습니다. 캡처는 더미 관리자 계정으로 연 실제 목록 화면입니다.
- 총 프로젝트 수는 46개이며 클린온은 개발/디자인/퍼블리싱 필터에서 동일한 상세를 공유합니다.

## 모두의 발주

제공된 mobal_front-main.zip의 Vue 3 + Vite 소스와 사용자가 확인한 디자인·프론트엔드 담당 범위를 근거로 추가했습니다. 원본 Vite 빌드는 통과했습니다. 실제 테스트 계정으로 대시보드·발주 입력 모달을 열어 캡처했으며 테스트 데이터 기반임을 명시했습니다. 참고 프로젝트는 reference-projects 폴더에서 로컬로 실행하고 공개 배포하지 않습니다. 현재 실제 화면은 http://127.0.0.1:4176/app/dashboard 에서 확인할 수 있습니다. 포트폴리오에는 실제 서비스 링크로 등록하지 않았습니다. 총 47개 프로젝트이며 Frontend에는 5개가 표시됩니다.
